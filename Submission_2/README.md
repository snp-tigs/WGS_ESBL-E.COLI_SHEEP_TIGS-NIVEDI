# Reproducibility Data and Scripts: Whole-genome analysis reveals shared extended-spectrum β-lactamase-producing Escherichia coli lineages between migratory sheep and surrounding farm environments

**Description:**
This repository contains the datasets, metadata, and computational scripts required to reproduce the main figures (Figures 1–9) for the manuscript investigating the exchange of ESBL-producing *Escherichia coli* genomes between migratory sheep and surrounding farm environments.

To ensure transparency and reproducibility during peer review, the repository is strictly divided into two main directories: `data_main_figures/` (raw data, matrices, and metadata) and `script_main_figures/` (R scripts, Python scripts, and methodological instructions).
